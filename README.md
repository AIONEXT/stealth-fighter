# Stealth Fighter

A stealth-inspired concept aircraft designed using OpenSCAD.

## Features

- Parametric design
- Main wings
- Twin stabilizers
- Cockpit canopy
- Engine intakes
- Landing gear
- Weapon bay doors

## Software

- OpenSCAD
- VS Code
- GitHub
- Bambu Studio

## Printing

Printer: Bambu Lab

Layer Height: 0.16 mm

Infill: 10% Gyroid

Material: PLA+
